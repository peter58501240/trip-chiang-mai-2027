## 內容
- 六天行程、航班；住宿基準改為 BED Nimman（尼曼區），2027/2/2入住～2/7退房，五晚同一間，尚未正式訂房。
- 2027-02-02 晚餐與夜遊改以 BED Nimman 周邊為主；2027-02-03 從 BED 搭車進古城，泰服寫真與 Baan Landai 晚餐後搭車回 BED。
- 2027-02-04 從 BED 前往 Baan Kang Wat 藝術村，古城按摩及夜遊後搭車回 BED。
- 2027-02-05 從 BED 逛尼曼區、Khao Soi Mae Sai、One Nimman，再搭車前往 Kalm Village 日落瑜珈；夜間活動後返回 BED。
- 2027-02-06 Jing Jai Market 及 Santi Float in Sound，夜市與古城活動結束後返回 BED。
- 美食、地圖導航、官方預約連結、確認清單與出發提醒。

## 非常重要的限制
- 網站為規劃表，**沒有自動訂位、也不會即時監控營業時間**。
- 所有 2027 年指定日期的商家營業、課程場次、價格與訂位狀態都需要再跟店家核對。
- 勾選紀錄只儲存在使用者當前的瀏覽器 localStorage，不能跨裝置同步，也不會真的送出訂位。
- 部分網站連結指向供應商官方網站、預約平台，應由旅客自行核對條款。
- 餐廳不安排餐餐米其林；每個時段提供明確地點、Google 地圖與 A／B／C 選項，讓旅客依體力與現場狀況調整。
- BED Nimman 是尼曼商圈的 Adults Only 飯店，提供早餐與免費飲水；飛機噪音可能影響淺眠旅客，訂房前須確認房數／房型、適用年齡、噪音與退訂規定。
- 古城和尼曼屬不同區域，古城行程結束回 BED 以 Grab／計程車為主，不可把古城景點當成可步行回飯店。
- 2/6 恰逢農曆春節；週末市集和餐廳可能調整營業。
